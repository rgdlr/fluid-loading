# Security Policy

## Supported Versions

We release patches and security fixes for the current major/minor release branch.

| Version | Supported          |
| :---    | :---               |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Fluid Loading, please **do not open a public issue**. Instead, follow responsible disclosure:

1. **Email**: Send details of the vulnerability to **rodrigrtic@gmail.com**.
2. **Details to include**:
   - Description of the vulnerability and potential impact.
   - Minimal reproduction code or step-by-step instructions.
   - Any suggested mitigations or patches if available.

---

## Response Process

- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will confirm the vulnerability and determine its impact and severity.
- **Fix & Release**: A patched version will be prepared and published to npm as an expedited security release.
- **Credit**: If desired, we will publicly credit you in the release notes and advisory.
